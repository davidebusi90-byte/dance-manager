# Regole di Permesso e Modifica

- NON modificare MAI i file di codice sorgente senza prima aver chiesto esplicitamente il permesso all'utente.
- NON prendere iniziative che alterano il codice esistente se l'utente ha richiesto solo analisi, spiegazioni o se ha dato permesso solo per compiti specifici e limitati (es. aggiornare un database o fare un test).
- Attendi sempre un'approvazione chiara e inequivocabile prima di procedere con modifiche (es. prima di usare gli strumenti di replace content o write file) sui file del progetto.

## PRE-FLIGHT CHECK OBBLIGATORIO
- **PRIMA** di eseguire qualsiasi comando o chiamata a uno strumento (tool), devi includere nel tuo processo decisionale interno una riflessione esplicita in cui confermi di aver letto e compreso queste regole di autorizzazione. Se la tua azione comporta la modifica di un file, devi citare testualmente il permesso inequivocabile ricevuto dall'utente per quella precisa operazione. In assenza di questo, fermati e chiedi.
